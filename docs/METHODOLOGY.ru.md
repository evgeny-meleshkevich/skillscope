# Методика SkillScope

**Навыки.** Используются словарь и правила контекста `rules-1.2`, без платных AI-сервисов. Автоматические метки «требование», «будет плюсом», «упоминание», «тег источника» показываются раздельно. Тег не считается обязательным требованием. Метки могут ошибаться; карточка показывает фрагмент-основание. Качество не заявляется как проверенное на размеченной независимой выборке. Внешняя LLM и ее API не подключены.

**Доля.** Число уникальных вакансий с выбранным навыком делится на число всех вакансий текущего фильтра. Вакансии без распознанных навыков остаются в знаменателе; покрытие извлечением видно отдельно. Один навык считается один раз на вакансию. В разделе «Все упоминания» результат характеризует упоминания, а не только обязательные требования. Для аудита обязательных требований выберите «Требование (правила)».

**История.** До первого собственного сбора истории нет. Графики используют последний завершенный срез дня при одинаковых параметрах источника. Пропущенные дни не записываются как нули. Период в фильтре ограничивает возраст публикации относительно даты соответствующего среза. Это запас наблюдаемых объявлений, а не поток новых вакансий и не сезонный прогноз. Публикация без даты исключается при фильтре по возрасту; «Весь срез» ее включает.

**Срок публикации.** `first_seen` и `last_seen` доступны в карточке. Исчезновение из ограниченной выдачи не означает архивирование или найм; аналитика Time-to-Hire не заявляется.

**Зарплаты.** Полные вилки с явно известными валютой и периодом. Односторонние границы не включаются в общую медиану. Gross/net/unknown, час/месяц/год и валюты не смешиваются; конвертации нет. Для старого структурированного поля HH `salary` применяется его месячная семантика; текстовые предложения Remotive без явно указанного периода остаются unknown. Текст с OTE/commission/equity не становится вилкой базового оклада. Медиана середины вилки показывается только при N ≥ 30. В проверенном потоке Remotive были две сопоставимые почасовые вилки; интерфейс показывает их без агрегированной медианы.

**Обучение.** Взвешенное покрытие = сумма количеств вакансий для навыков с практикой / сумма количеств вакансий для всех обнаруженных навыков. «Упоминание» не является практикой. Уровень пользователь уточняет вручную. Покрытие не измеряет качество курса, освоение навыков или вероятность трудоустройства. Рекомендованные модули — шаблон практического проекта по отсутствующему навыку; трудоемкость и prerequisites автоматически не оцениваются.

**Отчет.** Сохраняет фильтры, итоговые значения и вакансии-основания одного фиксированного среза. Дальнейший сбор или изменение программы не меняет уже сохраненный отчет. Публичный сервер и многопользовательский доступ не настроены: сервис слушает только 127.0.0.1.
